Подробное описание

Класс для обработки блоков чанков.

Обрабатывает и обеспечивает правильную работу с блоками чанков.

◆ isTransparentLevel()

bool SimpleVoxelEngine::IrrEngine::ChunksMeshBlocksController::isTransparentLevel ( int numbermesh)

Проверка уровня мешей на полупрозрачность.

Аргументы
numbermeshНомер уровня.
Возвращает
Возвращает true, если материал уровня полупрозрачный (IMaterialRenderer::isTransparent()). Для таких уровней отключается запись в Z-буфер и сортируются треугольники.

◆ requestUpdateLevel()

void SimpleVoxelEngine::IrrEngine::ChunksMeshBlocksController::requestUpdateLevel ( int numbermesh)

Пересклейка уровня (или всех уровней) всех блоков в ближайшем update().

Нужна, когда меняются настройки, которые нельзя применить к готовым нодам: тип материала уровня, родительская нода мира или сдвиг его начала координат.

Аргументы
numbermeshНомер уровня; меньше 0 - все уровни.
