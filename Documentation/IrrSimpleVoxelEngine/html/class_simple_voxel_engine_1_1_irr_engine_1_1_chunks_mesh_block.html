Подробное описание

Класс, отвечающий за объединение чанков в общие блоки.

Это необходимо для уменьшения числа вызовов отрисовки. Но увеличение размера данного блока уменьшает скорость обновления чанка. Приходится искать золотую середину.

◆ sortTransparentTriangles()

void SimpleVoxelEngine::IrrEngine::ChunksMeshBlock::sortTransparentTriangles ( irr::core::vector3df camerapos)

Сортировка треугольников от дальних к ближним относительно камеры.

Нужна для полупрозрачных материалов: они рисуются без записи в Z-буфер, поэтому дальние грани должны рисоваться раньше ближних. Пересортировка происходит, только если камера сместилась больше чем на TRANSPARENT_SORT_CAMERA_THRESHOLD или меш был перестроен. Ноды блоков стоят в центре блока, поэтому Irrlicht правильнее сортирует и сами ноды между собой.

Аргументы
cameraposПозиция камеры в глобальных координатах сцены.

◆ testOcclusionQuerie()

bool SimpleVoxelEngine::IrrEngine::ChunksMeshBlock::testOcclusionQuerie ( )

Проверка на прохождение условия Occlusion Queries.

Показывает или скрывает ноду по результату проверки. При проверке по ограничивающему кубоиду нода, внутри кубоида которой стоит камера (с запасом в две ближние плоскости отсечения), видна всегда.

Возвращает
Возвращает true, если блок чанков виден, иначе false.
