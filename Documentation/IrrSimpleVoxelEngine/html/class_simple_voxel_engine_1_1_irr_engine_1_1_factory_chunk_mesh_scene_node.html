Подробное описание

Фабрика для управления Irrlicht-нодами чанков.

Данный класс управляет и контролирует все операции, которые производятся с нодами чанков.

◆ clear()

void SimpleVoxelEngine::IrrEngine::FactoryChunkMeshSceneNode::clear ( )

Полная очистка фабрики.

Удаляет все чанки из отрисовки (deleteAllChunks()), ещё не применённые меши, миры фабрики (контроллеры блоков с их настройками и World3DInfo) и уровни мешей (число уровней становится 0). Вызывается деструктором. Вызывать в главном потоке, когда фабрика больше не нужна (после остановки движка): миры, добавленные до очистки, фабрика больше не рисует. Разморозка не происходит: незамороженной фабрике для дальнейшей работы нужно снова вызвать setNumberOfMeshesSceneNodeForChunk(), замороженную (отданную движку) использовать дальше нельзя.

◆ createFaceMesh()

irr::scene::IMesh * SimpleVoxelEngine::IrrEngine::FactoryChunkMeshSceneNode::createFaceMesh ( irr::f32 texinset = 0.002f)
static

Создание меша грани для getMeshCubeFaces().

Квадрат со стороной 1 с центром в начале координат, в плоскости Oxz лицевой стороной вверх (+Y) - ровно такой, какой ждёт getMeshCubeFaces(), поэтому модель грани из файла (например, models/plane3.obj) не нужна. Меш совпадает с plane3.obj из TestProject3 в том виде, в каком его загружает Irrlicht: те же вершины, порядок индексов и направление текстуры (u растёт к -X, v - к +Z). Один мешбуфер SMeshBuffer: 4 вершины S3DVertex (нормаль +Y, белый цвет), 2 треугольника, материал по умолчанию (SMaterial). Текстуру, тип материала и цвет вершин задаёт пользователь. Irrlicht (устройство) не нужен, вызывать можно из любого потока; обычно грань создают в конструкторе своей фабрики и удаляют в её деструкторе.

Аргументы
texinsetОтступ текстурных координат от краёв текстуры (от 0 до 0.5, вне - прижимается к границе): координаты идут от texinset до 1 - texinset, чтобы при фильтрации на краях грани не проступал противоположный край текстуры. 0 - координаты ровно от 0 до 1.
Возвращает
Возвращает новый меш (счётчик ссылок 1): когда он больше не нужен, вызовите у него drop().

◆ getMeshVoxel()

virtual irr::scene::IMesh * SimpleVoxelEngine::IrrEngine::FactoryChunkMeshSceneNode::getMeshVoxel ( SimpleVoxelEngine::Core::VoxelForRendering * vxlfr)
protectedpure virtual

Получение меша вокселя.

Пользовательская функция. Вызывается для получения меша вокселя, который будет "вклеен" в чанк. Вызывается в потоках построения (не в главном потоке), вызовы getMeshVoxel() и getMeshNumber() идут строго по одному (под общей блокировкой фабрики) - общие временные меши можно не защищать. Меш задаётся в координатах вокселя (центр - начало координат) и в его размере: позицию и поворот вокселя добавляет фабрика, масштаб - нет (его учитывают getMeshCubeFaces() и сам пользователь). Фабрика один раз вызывает drop() возвращённого меша: верните новый меш (как getMeshCubeFaces() и getMeshVoxelByGlue()) или вызовите grab() у своего перед возвратом.

Аргументы
vxlfrУказатель на информацию для отрисовки данного вокселя.
Возвращает
Возвращает указатель на меш данного вокселя, вклеиваемый в чанк. NULL - ошибка: меш чанка не строится (ошибка в логе).

Получение меша вокселя с отсечёнными невидимыми гранями из склейки указанных мешей. Грани являются своими мешами.

Данная функция даёт возможность склеивать воксель из любых мешей с учётом невидимых граней.

Аргументы
vxlfrУказатель на информацию для отрисовки данного вокселя. В нём так же содержится информация о видимости граней.
gluesМассив из 7 указателей: glues[0] приклеивается всегда (например, внутренняя часть вокселя; может быть NULL), glues[1]..glues[6] - меши граней, приклеиваются только видимые грани, в порядке массива видимости x+, z+, x-, z-, y+, y- (см. void SimpleVoxelEngine::IrrEngine::FactoryChunkMeshSceneNode::update ( )

Главная функция, отвечающая за работу фабрики.

При вызове данной функции происходит обработка всех задач, находящихся в очереди: готовые меши чанков превращаются в Irrlicht-ноды, у прозрачных уровней сортируются треугольники относительно активной камеры. Вызывается из IrrSimpleVoxelEngine::update(), только в главном потоке (потоке Irrlicht). Occlusion Queries здесь не выполняются - см. runOcclusionQueries().
