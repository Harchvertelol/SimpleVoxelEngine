Подробное описание

Главное пространство имён IrrSimpleVoxelEngine.

Здесь находятся все объекты и компоненты враппера.

Перечисления

◆ STREAM_CHUNK_ACTION

enum SimpleVoxelEngine::IrrEngine::STREAM_CHUNK_ACTION

Действие пула стриминга над одним чанком.

Элементы перечислений
STREAM_CHUNK_LOAD 

Загрузить чанк в память (с диска или генератором).

STREAM_CHUNK_RENDER 

Поставить загруженный чанк в отрисовку.

STREAM_CHUNK_UNRENDER 

Убрать чанк из отрисовки (данные остаются в памяти).

STREAM_CHUNK_UNLOAD 

Выгрузить чанк из памяти (не отрисовываемый).

◆ STREAM_CHUNK_RESULT

enum SimpleVoxelEngine::IrrEngine::STREAM_CHUNK_RESULT

Результат действия пула стриминга.

Элементы перечислений
STREAM_CHUNK_DONE 

Выполнено пулом.

STREAM_CHUNK_ALREADY 

Делать нечего: чанк уже в нужном состоянии (например, его загрузили не через пул).

STREAM_CHUNK_FAILED 

Не удалось (нет мира, чанк не загрузился или не сохранился).

◆ STREAMING_POSITION_MODE

enum SimpleVoxelEngine::IrrEngine::STREAMING_POSITION_MODE

Как задано положение контроллера стриминга.

Элементы перечислений
STREAMING_POSITION_NONE 

Положение ещё не задано - контроллер ничего не загружает.

STREAMING_POSITION_CHUNK 

Задан чанк (setChunkPosition()).

STREAMING_POSITION_WORLD 

Задана точка в координатах мира (setWorldPosition()).

STREAMING_POSITION_SCENE 

Задана точка в координатах сцены Irrlicht (setScenePosition()).

◆ STREAMING_SHAPE

enum SimpleVoxelEngine::IrrEngine::STREAMING_SHAPE

Форма области чанков контроллера стриминга.

Элементы перечислений
STREAMING_SHAPE_CUBOID 

Кубоид: чанки, у которых |dx| <= rx, |dy| <= ry, |dz| <= rz от центра.

STREAMING_SHAPE_CYLINDER 

Цилиндр с вертикальной осью: круг (эллипс) по X и Z с радиусами rx и rz, по Y - |dy| <= ry.

STREAMING_SHAPE_ELLIPSOID 

Шар (эллипсоид) с радиусами rx, ry, rz; при одинаковых радиусах - шар.

Элементы перечислений

Немедленное обновление чанков.

STOP 

Остановка рабочего потока. Ставит только IrrSimpleVoxelEngine::stop(), через addMainTask() не ставить (в отладочной сборке, SVE_DEBUG_CHECKS, addMainTask() его отклоняет).

SET_USER_CONTROLLER_FOR_THREAD

SAVE_CHUNKS 

Сохранение всех загруженных чанков мира (см. IrrSimpleVoxelEngine::saveAllChunks()).

STREAM_CHUNKS 

Действия пула стриминга чанков. Ставит только ChunkStreamingPool, вручную не ставить.
