Подробное описание

Меш для склейки (батчинга) многих мешей в один.

Нужен, чтобы сократить число вызовов отрисовки: вместо сотен маленьких мешей (по мешу на воксель или на чанк) рисуется несколько больших. Исходные мешбуферы добавляются с позицией, поворотом и масштабом (или с матрицей преобразования). Буферы с одинаковым материалом и типом вершин объединяются в один буфер назначения (до 65535 вершин в буфере; если места не хватает, создаётся ещё один буфер с тем же материалом).

Порядок работы:

  1. addMesh() / addMeshBuffer() - добавить исходные меши (сам меш при этом ещё не меняется);
  2. update() - скопировать вершины и индексы исходных буферов в буферы назначения с учётом преобразований;
  3. по желанию finalize() - отпустить исходные буферы, после этого меш больше нельзя менять (кроме clear(), после которого его можно заполнять заново).

Ограничения:

  • исходные буферы должны использовать 16-битные индексы (буферы с 32-битными индексами не принимаются);
  • нормали преобразуются поворотом и масштабом и затем нормализуются - для неравномерного масштаба (разного по осям) результат приближённый;
  • класс не потокобезопасен: один объект нельзя одновременно менять из разных потоков.

Используется враппером: каждый чанк строится в своём CBatchingMesh в потоке построения, а ChunksMeshBlock склеивает меши чанков блока в один CBatchingMesh в главном потоке.

◆ clear()

void irr::scene::CBatchingMesh::clear ( )

Полная очистка меша.

Отпускает все буферы (и исходные, и назначения) и сбрасывает состояние, в том числе запрет изменений после finalize(). После этого меш можно заполнять заново.

◆ finalize()

void irr::scene::CBatchingMesh::finalize ( )

Завершение построения меша.

Вызывает update(), затем отпускает исходные буферы (экономия памяти). После этого меш нельзя менять: addMesh(), addMeshBuffer(), moveMesh() и moveMeshBuffer() перестают работать, getSourceBuffer() возвращает NULL. Снять запрет можно только вызовом clear().

◆ update()

void irr::scene::CBatchingMesh::update ( )

Обновление буферов назначения из исходных буферов.

Выделяет память под вершины и индексы, копирует в изменившиеся буферы назначения вершины исходных буферов с учётом их преобразований и пересчитывает ограничивающие объёмы. Вызывайте после добавления буферов.
