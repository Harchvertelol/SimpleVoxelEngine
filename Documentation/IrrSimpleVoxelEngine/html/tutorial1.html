Урок 1: Hello, world!

В этом уроке мы нарисуем свой первый воксельный мир: один чанк с цветным полом 16x16 вокселей и камеру, которой можно по нему полетать. Это тот же пример, что и на главной странице документации, только теперь мы разберём его по строкам: зачем нужна каждая часть, в каком потоке она работает и что будет, если её забыть. Никаких файлов (моделей, текстур) для урока не нужно.

Перед началом стоит пройти хотя бы первый урок SimpleVoxelEngine (что такое мир, чанк, воксель) и настроить проект, как описано в разделе "Настройка движка": подключить папки include враппера, SimpleVoxelEngine и Irrlicht, а библиотеки - в порядке "враппер, SimpleVoxelEngine, Irrlicht".

Кто есть кто

В программе работают три участника:

  • Irrlicht - графический движок: окно, сцена, ноды, драйвер. Рисует именно он.
  • SimpleVoxelEngine (ядро) - хранит воксельный мир: миры, чанки, воксели, адреса; считает, какие грани вокселей видны. О графике он ничего не знает и сам по себе не потокобезопасен.
  • IrrSimpleVoxelEngine (враппер) связывает их. Класс IrrSimpleVoxelEngine унаследован от Engine ядра, то есть это и есть движок SimpleVoxelEngine, только с графикой и потоками. Он превращает чанки в ноды Irrlicht, а всю тяжёлую работу (загрузку чанков, изменение мира, построение мешей) выполняет в фоновых потоках.

Одного враппер не знает: как выглядит ваш воксель. Куб? Растение? Какого цвета, с какой текстурой? Это ему рассказывает фабрика - ваш класс, унаследованный от FactoryChunkMeshSceneNode. Без фабрики враппер не работает.

Подключаем

Начнём, как обычно, с заголовков и пространств имён:

#include <irrlicht.h>

Фабрика

Теперь самое интересное - фабрика. Когда враппер строит меш чанка, он берёт у ядра список видимых вокселей чанка и для каждого спрашивает у фабрики: "какой меш нарисовать на месте этого вокселя?". Потом склеивает все эти меши в один большой меш чанка, а из него делает ноду сцены.

class MyFactory : public FactoryChunkMeshSceneNode
{
public:
MyFactory(IrrlichtDevice* device, IrrSimpleVoxelEngine* isve) : FactoryChunkMeshSceneNode(device, isve)
{
s_Plane = createFaceMesh(); // Грань 1x1, из которой getMeshCubeFaces() собирает куб (файл модели не нужен).
s_MeshManipulator = device->getSceneManager()->getMeshManipulator(); // Всё, что требует Irrlicht, - здесь, в главном потоке.
}
~MyFactory() { s_Plane->drop(); } // Грань создали мы - мы её и удаляем.

Конструктор получает устройство Irrlicht и враппер и передаёт их предку. Здесь же мы готовим всё, что понадобится при рисовании: грань куба и манипулятор мешей Irrlicht.

createFaceMesh() - статическая функция фабрики: она создаёт квадрат 1x1 с центром в начале координат, лежащий в плоскости Oxz лицом вверх (+Y). Ровно из таких граней getMeshCubeFaces() собирает куб. Меш новый, поэтому, когда он больше не нужен, ему нужно сделать drop() - что мы и делаем в деструкторе. Саму фабрику удалит враппер (об этом ниже).

Почему всё готовится в конструкторе? Потому что функции рисования фабрики вызываются не в главном потоке, а в потоках построения мешей. А трогать сцену и драйвер Irrlicht (загружать меши и текстуры, создавать ноды) можно только из главного потока - того, где создано окно и вызывается drawAll(). Конструктор фабрики работает в главном потоке, поэтому всё нужное создаём в нём.

Дальше - две обязательные функции:

protected:
// Вызывается в потоках построения для каждого видимого вокселя: вернуть НОВЫЙ меш (враппер сам сделает ему drop()).
IMesh* getMeshVoxel(VoxelForRendering* vxl)
{
IMesh* mesh = getMeshCubeFaces(vxl, s_Plane, vector3df(1, 1, 1)); // Куб только из видимых граней.
ARGBColor c = ((VoxelInfoARGBColor*)vxl->getVoxelInfo())->s_ARGBColor; // Цвет нашего ARGBColorVoxel.
if(mesh) s_MeshManipulator->setVertexColors(mesh, SColor(c.getA(), c.getR(), c.getG(), c.getB()));
return mesh;
}
int getMeshNumber(VoxelForRendering*) { return 0; } // Все воксели - в одном уровне мешей (одном материале).
IMesh* s_Plane;
IMeshManipulator* s_MeshManipulator;
};

getMeshVoxel() получает VoxelForRendering - "снимок" вокселя, сделанный ядром: его позицию и размер, видимость каждой из шести граней и информацию для отрисовки (VoxelInfo), которую дал сам воксель. Подробно о VoxelForRendering и VoxelInfo рассказано в уроке 5 SimpleVoxelEngine. У встроенного ARGBColorVoxel информация - это VoxelInfoARGBColor с цветом, поэтому мы смело приводим тип: других вокселей в нашем мире нет. (Если в мире разные типы вокселей, сначала проверьте поле s_TypeVoxelInfo.)

getMeshCubeFaces() собирает куб только из видимых граней: грань между двумя соседними вокселями не видна, и её в меше просто нет. Именно поэтому сплошной чанк из 4096 вокселей рисуется быстро - от него остаются только внешние грани. Третий параметр - множитель размера куба, (1, 1, 1) - куб ровно в размер вокселя.

Меш вокселя задаётся в координатах вокселя (центр - в начале координат), а на нужное место его поставит сама фабрика. getMeshCubeFaces() возвращает новый меш, мы красим его вершины в цвет вокселя и отдаём врапперу; враппер вклеит меш в чанк и сам сделает ему drop(). Отдавать нужно именно новый меш: если вернуть, например, s_Plane, враппер сделает ему drop(), и грань удалится.

setVertexColors() вызывать в потоке построения можно: манипулятор меняет только вершины переданного меша и сцены не касается. А вот, например, getVideoDriver()->getTexture() здесь вызывать уже нельзя.

getMeshNumber() говорит, в какой уровень мешей попадёт воксель. Уровни - это части меша чанка со своими материалами (например, отдельный уровень для стекла или воды). У нас уровень один, номер 0. Подробнее - в уроке 9.

И ещё одна приятная вещь: getMeshVoxel() и getMeshNumber() вызываются строго по одному, даже если потоков построения несколько, - враппер держит для этого свою блокировку. Поэтому общую грань s_Plane можно использовать без мьютексов. Как это помогает делать разные текстуры, расскажем в уроке 3.

Создаём движок и мир

Переходим к main(). Создаём устройство Irrlicht и враппер:

int main()
{
IrrlichtDevice* device = createDevice(EDT_OPENGL, dimension2d<u32>(800, 600)); // Окно Irrlicht.
IrrSimpleVoxelEngine* isve = new IrrSimpleVoxelEngine(device); // Создали враппер (внутри - движок SimpleVoxelEngine).

Кстати, мы создали враппер без логгера. Это значит, что движок молчит обо всём - и об ошибках тоже: если что-то пойдёт не так, вы ничего не увидите. Для первого примера так проще, но в своих программах логгер лучше подключать сразу (как - в уроке 2).

Теперь фабрика и её масштабы:

MyFactory* factory = new MyFactory(device, isve);
factory->setPositionScale(16); // Масштабы - равны размеру чанка (16): один воксель - одна единица сцены.
factory->setSScale(16);

Зачем масштабы? Ядро отдаёт позицию и размер вокселя в долях чанка: воксель чанка 16x16x16 имеет размер 1/16. Фабрика умножает позицию на setPositionScale(), а размер - на setSScale(). Ноды же чанков враппер ставит с шагом в размер чанка, то есть через 16 единиц. Поэтому оба масштаба ставьте равными размеру чанка: тогда воксель - ровно одна единица сцены, а чанки стоят вплотную. По умолчанию масштабы равны 1, и при чанке 16 воксели получаются крошечными (1/16), а между чанками - промежутки.

Отдаём фабрику врапперу:

isve->setFactoryChunkMeshSceneNode(factory); // Фабрику - ДО создания мира. Удалит её враппер.

С этого момента фабрикой владеет враппер: удалять её самим нельзя, её удалит delete isve. Ещё фабрика "замораживается": масштабы и другие основные настройки больше не меняются (такие вызовы вернут false и запишут ошибку в лог). Поэтому все такие настройки - до этой строки. Фабрика у движка одна, вторую он не примет. Получить установленную фабрику можно через isve->getFactoryChunkMeshSceneNode(), а устройство Irrlicht враппера - через isve->getIrrlichtDevice().

Фабрику обязательно отдать до создания мира: addWorld() регистрирует мир и в фабрике, и без фабрики вернёт -1. Создаём мир:

int id = isve->addWorld(); // Мир по умолчанию: чанк 16x16x16 вокселей.
factory->setMaterialFlag(0, id, EMF_LIGHTING, false); // Без источников света: виден цвет вершин.

addWorld() без параметров создаёт мир с чанками 16x16x16 и возвращает его идентификатор (или -1 при ошибке). Вызывать его можно только из главного потока.

setMaterialFlag() ставит флаг материала нодам чанков: первый параметр - номер уровня мешей, второй - мир. Света в нашей сцене нет, и с включённым освещением всё было бы чёрным, поэтому освещение выключаем - и видим цвет вершин. Флаги материала можно менять и во время работы (тоже только из главного потока): они применяются и к уже созданным нодам.

Наполняем мир

isve->addChunksForRendering(id, Vector3d<int>(0, 0, 0), Vector3d<int>(0, 0, 0), true); // Загрузить (здесь - создать пустой) чанк (0,0,0).

addChunksForRendering() добавляет в отрисовку все чанки кубоида от левого нижнего угла до правого верхнего (оба включительно) - у нас это один чанк (0, 0, 0). Сама функция ничего не загружает: она ставит задание в главную очередь заданий враппера, а выполнит его поток главной очереди после start(). Последний параметр load = true разрешает загрузить чанк, которого нет в памяти: его загрузит контроллер сохранения или создаст генератор мира (урок 2). У нас нет ни того, ни другого, поэтому чанк получится пустым (в логе было бы предупреждение об этом). С load = false чанк, которого нет в памяти, в отрисовку не попадёт - частая причина "ничего не рисуется".

Теперь пол:

for(int x = 0; x < 16; x++)
for(int z = 0; z < 16; z++) // Пол из цветных вокселей 16x16.
{
ARGBColorVoxel* vxl = new ARGBColorVoxel; // Встроенный воксель с одним параметром - цветом.
vxl->setARGBColor(ARGBColor(255, x * 16, 128, z * 16));
isve->setSimpleVoxelObjectByGlobalVector(id, Vector3d<int>(x, 0, z), vxl); // Воксель забирает враппер.
}
isve->addTaskUpdateChunks(); // Перестроить изменённые чанки (один раз - после всех изменений).

setSimpleVoxelObjectByGlobalVector() ставит воксель по глобальным координатам - номеру клетки во всём мире: чанк (0, 0, 0) занимает клетки от 0 до 15 по каждой оси, чанк (1, 0, 0) - от 16 до 31 и так далее (отрицательные координаты тоже работают). В каком чанке клетка и где она внутри чанка, враппер считает сам. Воксель после вызова принадлежит врапперу: не удаляйте его и не храните указатель на него.

Эта функция потокобезопасна, но из главного потока она воксель сразу не ставит, а тоже кладёт задание в главную очередь. Задания выполняются строго по порядку, поэтому к моменту установки вокселей чанк (0, 0, 0) уже будет загружен. Если же к моменту выполнения чанка в памяти нет, воксель не ставится и удаляется (с предупреждением в логе).

Где окажется воксель на экране? Блок с глобальными координатами k занимает отрезок от k - 0.5 до k + 0.5, то есть центры блоков лежат в целых точках. Наш пол занимает от -0.5 до 15.5 по X и Z, а его верх - на высоте 0.5.

addTaskUpdateChunks() нужна потому, что мир не перестраивается сам при каждом изменении. Установка вокселя только помечает его чанк (и соседний, если воксель на краю чанка) "для обновления", а addTaskUpdateChunks() ставит все помеченные чанки на перестройку. Так 256 изменений дают одну перестройку чанка, а не 256. Вызывайте её один раз после пачки изменений. Забудете - изменения не появятся на экране (или появятся частично).

Добавим камеру (FPS-камера: мышь - поворот, стрелки - движение):

ICameraSceneNode* camera = device->getSceneManager()->addCameraSceneNodeFPS();
camera->setPosition(vector3df(8, 10, -10));
camera->setTarget(vector3df(8, 0, 8));

Запуск и главный цикл

isve->start(); // Запустили потоки враппера: дальше чанки строятся в фоне.

start() запускает потоки враппера: поток главной очереди (он по порядку выполняет задания: загрузку чанков, установку вокселей и т.д.) и потоки построения мешей. Задания, поставленные до start(), начинают выполняться только теперь. Без start() ничего не загрузится и не построится - задания будут просто ждать. Запустить можно только движок с фабрикой. Работает ли движок (живы ли его потоки), скажет isRun().

while(isve->runIrrDevice()) // То же, что device->run(), но безопасно для потоков враппера.
{
isve->update(); // Каждый кадр в главном потоке: готовые меши чанков становятся нодами сцены.
device->getVideoDriver()->beginScene(true, true, SColor(255, 100, 100, 140));
device->getSceneManager()->drawAll();
device->getVideoDriver()->endScene();
}

runIrrDevice() вызывает device->run() и заодно запоминает время таймера Irrlicht, чтобы другие потоки могли безопасно узнавать его через getTimeSafeThread() (обычный device->run() тоже работает: время запоминает и update()).

update() - самая важная строка цикла. Потоки построения только готовят меши чанков, а в сцену их добавляет главный поток - внутри update(): создаёт и заменяет ноды чанков, склеивает соседние чанки в одну ноду, сортирует прозрачные треугольники. Вызывайте update() каждый кадр и только из главного потока. Забудете - на экране ничего не появится, а готовые меши так и будут ждать. Ноды чанков принадлежат врапперу: не удаляйте их сами.

Остальное - обычный кадр Irrlicht.

Остановка и удаление

isve->stop(); // Дождались выполнения всех заданий и остановили потоки.
delete isve; // Удалили враппер, мир и фабрику.
device->drop(); // Последним - устройство Irrlicht.
return 0;
}

stop() ставит в конец главной очереди задание "стоп": все задания, поставленные раньше, будут выполнены, после чего потоки завершатся, а stop() их дождётся. После stop() потоки миром не пользуются, и с ним можно работать напрямую (например, сохранить - урок 11). Не вызывайте stop() из функций фабрики (они работают в потоках построения) и из пользовательских функций в потоке главной очереди (урок 10): поток ждал бы сам себя. У stop() есть параметр wait (по умолчанию true - дождаться потоков); stop(false) и повторный start() после остановки разобраны в уроке 10.

delete isve убирает ноды чанков, удаляет фабрику и миры (если движок ещё работает, он сам сначала вызовет stop()). Устройство Irrlicht удаляем последним: фабрика и ноды чанков пользуются им до самого delete isve, и если сделать device->drop() раньше, программа упадёт при удалении враппера.

Типичные ошибки

  • Ничего не рисуется: забыли isve->update() в цикле; забыли start(); фабрику отдали после addWorld() (addWorld() вернул -1); addChunksForRendering() с load = false для чанков, которых нет в памяти.
  • Воксели крошечные, между чанками промежутки: setPositionScale() и setSScale() не равны размеру чанка.
  • Изменения не видны: после установки вокселей не вызван addTaskUpdateChunks().
  • Всё чёрное: освещение включено, а источников света в сцене нет (EMF_LIGHTING).
  • Ошибок не видно совсем: движок создан без логгера.
  • Масштаб или другие настройки фабрики "не действуют": они заданы после setFactoryChunkMeshSceneNode().
  • Падения в случайных местах: в getMeshVoxel() трогают сцену или драйвер Irrlicht (это поток построения), или device->drop() вызван раньше delete isve.
  • Программа зависла на выходе: stop() вызван из функции фабрики.

s_MeshManipulator = device->getSceneManager()->getMeshManipulator(); // Всё, что требует Irrlicht, - здесь, в главном потоке.
}
~MyFactory() { s_Plane->drop(); } // Грань создали мы - мы её и удаляем.
protected:
// Вызывается в потоках построения для каждого видимого вокселя: вернуть НОВЫЙ меш (враппер сам сделает ему drop()).
IMesh* getMeshVoxel(VoxelForRendering* vxl)
{
IMesh* mesh = getMeshCubeFaces(vxl, s_Plane, vector3df(1, 1, 1)); // Куб только из видимых граней.
ARGBColor c = ((VoxelInfoARGBColor*)vxl->getVoxelInfo())->s_ARGBColor; // Цвет нашего ARGBColorVoxel.
if(mesh) s_MeshManipulator->setVertexColors(mesh, SColor(c.getA(), c.getR(), c.getG(), c.getB()));
return mesh;
}
int getMeshNumber(VoxelForRendering*) { return 0; } // Все воксели - в одном уровне мешей (одном материале).
IMesh* s_Plane;
IMeshManipulator* s_MeshManipulator;
};
int main()
{
IrrlichtDevice* device = createDevice(EDT_OPENGL, dimension2d<u32>(800, 600)); // Окно Irrlicht.
IrrSimpleVoxelEngine* isve = new IrrSimpleVoxelEngine(device); // Создали враппер (внутри - движок SimpleVoxelEngine).
MyFactory* factory = new MyFactory(device, isve);
factory->setPositionScale(16); // Масштабы - равны размеру чанка (16): один воксель - одна единица сцены.
factory->setSScale(16);
isve->setFactoryChunkMeshSceneNode(factory); // Фабрику - ДО создания мира. Удалит её враппер.
int id = isve->addWorld(); // Мир по умолчанию: чанк 16x16x16 вокселей.
factory->setMaterialFlag(0, id, EMF_LIGHTING, false); // Без источников света: виден цвет вершин.
isve->addChunksForRendering(id, Vector3d<int>(0, 0, 0), Vector3d<int>(0, 0, 0), true); // Загрузить (здесь - создать пустой) чанк (0,0,0).
for(int x = 0; x < 16; x++)
for(int z = 0; z < 16; z++) // Пол из цветных вокселей 16x16.
{
ARGBColorVoxel* vxl = new ARGBColorVoxel; // Встроенный воксель с одним параметром - цветом.
vxl->setARGBColor(ARGBColor(255, x * 16, 128, z * 16));
isve->setSimpleVoxelObjectByGlobalVector(id, Vector3d<int>(x, 0, z), vxl); // Воксель забирает враппер.
}
isve->addTaskUpdateChunks(); // Перестроить изменённые чанки (один раз - после всех изменений).
ICameraSceneNode* camera = device->getSceneManager()->addCameraSceneNodeFPS();
camera->setPosition(vector3df(8, 10, -10));
camera->setTarget(vector3df(8, 0, 8));
isve->start(); // Запустили потоки враппера: дальше чанки строятся в фоне.
while(isve->runIrrDevice()) // То же, что device->run(), но безопасно для потоков враппера.
{
isve->update(); // Каждый кадр в главном потоке: готовые меши чанков становятся нодами сцены.
device->getVideoDriver()->beginScene(true, true, SColor(255, 100, 100, 140));
device->getSceneManager()->drawAll();
device->getVideoDriver()->endScene();
}
isve->stop(); // Дождались выполнения всех заданий и остановили потоки.
delete isve; // Удалили враппер, мир и фабрику.
device->drop(); // Последним - устройство Irrlicht.
return 0;
}
