Подробное описание

Контроллер стриминга чанков - "игрок" или "камера", вокруг которых загружаются и отрисовываются чанки.

Создаётся и удаляется только пулом (ChunkStreamingPool::addController(), removeController()). У контроллера свой мир, своя форма и радиусы области и своё положение. Сам контроллер ничего не загружает: каждый шаг пула (ChunkStreamingPool::step()) пул по положениям всех контроллеров решает, какие чанки нужны, и ставит задания. Чанк может быть нужен нескольким контроллерам сразу (несколько игроков рядом) - тогда у него несколько владельцев, и выгружается он, только когда не нужен ни одному. Область: чанки формы getShape() с радиусами getRadius() вокруг чанка контроллера отрисовываются; на один чанк дальше (кольцо данных) чанки только загружаются в память без отрисовки - чтобы на краю отрисованной области грани не рисовались там, где их потом закроет соседний чанк. Уже взятые чанки отпускаются только дальше радиуса + запас (getUnloadMargin()): при хождении по границе чанка чанки не загружаются и не выгружаются туда-сюда. Все функции - только из главного потока (там же, где вызывается ChunkStreamingPool::step()).

void SimpleVoxelEngine::IrrEngine::ChunkStreamingController::setRadius ( SimpleVoxelEngine::Additional::Vector3d< int > radius)

Установка радиусов области в чанках.

Радиусы по осям X, Y, Z (отрицательные заменяются на 0). 0 - только чанк контроллера по этой оси. Для цилиндра Y - половина высоты; если высота мира ограничена (World::setChunksBound()), чанки за границей не загружаются, сколько бы ни был радиус. По умолчанию (4, 2, 4).

Аргументы
radiusРадиусы.
