Открытые атрибуты

int s_RenderWanted = 0
 Сколько чанков контроллер держит в отрисовке (область).
int s_Rendered = 0
 Сколько из них уже загружено и отрисовывается (меш может ещё строиться).
int s_MemoryWanted = 0
 Сколько чанков контроллер держит в памяти (область с кольцом данных).
int s_Loaded = 0
 Сколько из них уже загружено в память.
int s_Failed = 0
 Сколько из них не загрузилось (ошибка генератора или контроллера загрузки; пул повторит позже).
int s_OutOfBounds = 0
 Сколько чанков области за границами мира (World::setChunksBound()) - их нет, они не загружаются.
int s_PendingActions = 0
 Сколько действий пула всех контроллеров ещё ждёт в главной очереди.
