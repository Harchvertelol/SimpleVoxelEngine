Подробное описание

Пространство имён с предопределённым константами для работы движка.

Перечисления

◆ NUMBER_DEFINES

enum SimpleVoxelEngine::IrrEngine::IrrSVEDefines::NUMBER_DEFINES

Числовые константы.

Элементы перечислений
DEFAULT_NUMBER_OF_THREAD_ADD_CHUNKS 

Стандартное количество потоков для создания чанков (теперь это реальное число потоков пула, см. setMaxNumberOfThreadAddChunks).

DEFAULT_NUMBER_OF_THREAD_UPDATE_CHUNKS 

Стандартное количество потоков для обновления чанков (реальное число потоков пула, см. setMaxNumberOfThreadUpdateChunks).

TIMER_OCCLUSION_QUERIES_IN_MILLISECONDS 

Раз в это количество миллисекунд происходит пересчёт Occlusion Queries.

MAX_FRAMES_BETWEEN_OCCLUSION_QUERIES 

Occlusion Queries выполняются не реже, чем раз в это количество кадров (вызовов runOcclusionQueries()).

MAX_FRAMES_BETWEEN_OCCLUSION_QUERIES_LIMIT 

Наибольшее допустимое значение setMaxFramesBetweenOcclusionQueries(): Irrlicht удаляет Occlusion Query, которую не запускали больше 1000 кадров.

MAX_DELAY_GLUE_BLOCK_CHUNKS_IN_MILLISECONDS 

Сколько максимум склейка блока чанков может ждать, пока будут построены его новые чанки.

THREAD_WAIT_INTERVAL_IN_MILLISECONDS 

Как часто поток очереди и потоки построения, когда им нечего делать, проверяют, не появилась ли работа (на Windows фактически - до ~15 мс).

Переменные

◆ TRANSPARENT_SORT_CAMERA_THRESHOLD

const float SimpleVoxelEngine::IrrEngine::IrrSVEDefines::TRANSPARENT_SORT_CAMERA_THRESHOLD = 0.25f

Насколько (в единицах сцены, в локальных координатах ноды) должна сместиться камера, чтобы полупрозрачные треугольники блока были пересортированы.

Сортировать каждый кадр дорого, а при маленьком смещении камеры порядок треугольников почти не меняется.
