Подробное описание

Система проверки SimpleVoxelObject на прозрачность.

Несмотря на кажущуюся простоту, эта система даёт много возможностей. Например, создание граней только между определёнными типами вокселей. Вложенные чанки (ChunkVoxelObject) тестеру не передаются: движок сам проверяет ячейки вложенного чанка, которые касаются грани (World::isFaceTransparent()), и для каждого блока среди них вызывает тестер. Если parent - вложенный чанк, вместо него передаётся NULL.
