Регистрация событий.

Все сообщения движка (миров, чанков, адресов) идут через эту функцию; она передаёт их логгеру (getLogger()), если он установлен, а логгер выводит те типы сообщений, которые у него включены. Функцию можно переопределить в наследнике движка - например, чтобы дополнительно записывать сообщения в файл или фильтровать их по-своему. Переопределённая функция может вызвать эту (Engine::registerEvent()), чтобы сообщение всё равно попало в логгер. Если не переопределять, работает вывод логгера, как есть.

Аргументы
TypeEventТип регистрируемого события.
TextEventТекст сообщения для логгера.
IsFatalЕсли имеет значения true, то событие является фатальным. Рекомендуется прекратить работу с программой.
