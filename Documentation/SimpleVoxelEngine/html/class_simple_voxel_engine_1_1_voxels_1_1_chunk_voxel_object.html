Подробное описание

Чанк.

Данный класс является чанком, т.е. куском воксельного мира. Весь воксельный мир грузится по частям, которые и называются чанками.

◆ createData()

void SimpleVoxelEngine::Voxels::ChunkVoxelObject::createData ( )

Создать необходимые хранилища для SimpleVoxelObject.

Создаёт массивы, хранящие указатели на SimpleVoxelObject и вспомогательные. Данная функция является специальной и не рекомендуется для частого использования, этот параметр контролируется внутренней системой чанка. Только в случае ручной работы с данными чанка необходимо создавать правильную комбинацию параметров. Подробнее см. уроки. Внимание: сначала вызывается deleteData() - если массивы уже есть, все воксели чанка удаляются (счётчик - 0). Обычно createData() вызывать не нужно: getSimpleVoxelObjects() и похожие функции создают массивы сами.

◆ setNumberOfPartitions()

bool SimpleVoxelEngine::Voxels::ChunkVoxelObject::setNumberOfPartitions ( unsigned char numberofpartitions)

Установка длины ребра куба чанка.

Куб чанка нелогично делать более 255 блоков, поэтому тип unsigned char. Установка (и смена) возможна только в "чистый" чанк, где ещё нет вокселей, иначе false. Например, генератор может задать чанку разбиение, отличное от World::getSizeChunk(). Массивы, созданные до установки, удаляются и потом создаются заново нужного размера.

Аргументы
numberofpartitionsУстанавливаемая длина ребра куба чанка (больше 0).
Возвращает
Возвращает true, если успешно. Иначе false (0 или чанк не пуст).

◆ setReCalculateVisibleCacheBorder()

void SimpleVoxelEngine::Voxels::ChunkVoxelObject::setReCalculateVisibleCacheBorder ( int axis,
bool high )

Пометка на пересчёт видимости граничного слоя вокселей.

Помечаются все существующие воксели, касающиеся грани чанка, а у вложенных чанков в этом слое - их граничный слой с той же стороны. Нужна, когда рядом загрузился или выгрузился соседний чанк.

Аргументы
axisОсь, перпендикулярная грани (0 - x, 1 - y, 2 - z).
hightrue - слой с наибольшей координатой (getNumberOfPartitions() - 1), false - с координатой 0.

◆ setSimpleVoxelObject()

bool SimpleVoxelEngine::Voxels::ChunkVoxelObject::setSimpleVoxelObject ( SimpleVoxelEngine::Additional::Vector3d< int > vect,
SimpleVoxelEngine::Voxels::SimpleVoxelObject * svo,
bool rewrite = false,
bool setrecalculatearoundsvo = true )

Установка SimpleVoxelObject.

Устанавливает или изменяет SimpleVoxelObject по координатам vect внутри чанка.

Аргументы
vectВектор (координаты) SimpleVoxelObject внутри чанка.
svoSimpleVoxelObject, который устанавливается.
rewriteЕсли имеет значение true, то даже при наличии по координатам vect SimpleVoxelObject будет произведена установка svo (старый объект удаляется). Иначе не будет. Повторная установка того же объекта (svo уже лежит в ячейке) ничего не удаляет, а только помечает ячейку (и соседей, если setrecalculatearoundsvo) на пересчёт видимости - так можно сообщить движку, что объект изменили на месте (например, он стал прозрачным).
setrecalculatearoundsvoЕсли имеет значение true, то окружающие его SimpleVoxelObject будут добавлены в кэш анализа видимости. Иначе не будут.
Возвращает
Возвращает true в случае успеха, иначе false. При успехе svo принадлежит чанку (чанк удалит его сам), при false чанк его не забирает - удаляет вызывающий.
