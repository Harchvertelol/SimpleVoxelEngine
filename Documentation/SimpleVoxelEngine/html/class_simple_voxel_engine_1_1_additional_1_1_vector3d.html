template<typename TYPE_TypeCoord>
class SimpleVoxelEngine::Additional::Vector3d< TYPE_TypeCoord >

Шаблонный класс 3d вектора.

Данный класс содержит основные методы, необходимые для работы с векторами в 3d пространстве..

Конструктор по умолчанию.

Внимание: конструктор неявный, поэтому число само превращается в вектор (число, 0, 0) - например, v + 1 означает v + (1, 0, 0). Для сдвига на число по всем осям пишите v + Vector3d(1, 1, 1).

Получение нормализованного вектора.

Нулевой вектор не нормализуется: для float получится NaN, для int - деление на ноль. Для int результат к тому же округляется к нулю (почти всегда нулевой вектор) - используйте для float.

Возвращает
Возвращает нормализованный вектор.

Оператор сравнения "меньше или равно".

Внимание: "меньше" сравнивает точно, а "равно" - с допуском EPS (см. operator==), поэтому для float a < b и a == b могут быть верны одновременно. Для int всё согласовано.
