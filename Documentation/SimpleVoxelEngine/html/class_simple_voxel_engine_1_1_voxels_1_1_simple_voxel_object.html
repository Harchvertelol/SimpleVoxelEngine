virtual SimpleVoxelEngine::Core::VoxelInfo * SimpleVoxelEngine::Voxels::SimpleVoxelObject::getVoxelForRenderingInfo ( )
virtual

Получение информации для рендеринга.

Данная функция вызывается при получении от SimpleVoxelObject информации, которая будет отдана пользователю для отрисовки. Переопределите её в своём вокселе: нужно возвращать НОВЫЙ объект (new VoxelInfo или наследника) - его заберёт VoxelForRendering и удалит сам. Базовая реализация возвращает NULL (информации нет).

Возвращает
Возвращает указатель на новый VoxelInfo (или NULL).

Переопределяется в SimpleVoxelEngine::Voxels::ARGBColorVoxel.
