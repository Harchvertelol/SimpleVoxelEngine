◆ roundNumber()

int WorkFunctions::MathFunctions::roundNumber ( int number,
int divide,
int change )

Округление числа.

Округляет целое число до необходимой делимости.

Аргументы
numberОкругляемое число.
divideНа что должно делиться после округления.
changeНа сколько изменять число за шаг (Для округления вверх ставим 1, для округления вниз ставим -1). Если неправильно поставить change, то программа может зависнуть.
Возвращает
Возвращает округлённое число.
