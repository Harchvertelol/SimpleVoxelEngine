Подробное описание

Воксельный мир.

Данный класс является регистрируемым воксельным миром. Движок может содержать много воксельных миров.

bool createchunkinmemory = true,

Генерация чанка.

Генерирует чанк с помощью установленного генератора.

Аргументы
vectВектор (координаты) генерируемого чанка.
createchunkinmemoryСоздавать ли чанк в памяти (ставить true, если чанк не существует в памяти, иначе генерация не произойдёт). true для уже загруженного чанка и false для незагруженного - ошибка (false). Чанк, созданный здесь, при неудаче генерации удаляется. При генерации поверх уже загруженного чанка (false) чанк остаётся в памяти и при неудаче - с тем, что генератор успел записать; весь чанк помечается на пересчёт видимости. Подготовка после генерации - как в loadChunk(). Чанк за границами мира не генерируется (генератор не вызывается).
outboundserrorПисать ли в лог нарушение логики, если чанк за границами мира (false - молча вернуть false).
Возвращает
В случае успеха возвращает true, иначе false.

◆ getAddressesSimpleVoxelObjectsByFace()

std::vector< VoxelAddress * > SimpleVoxelEngine::Core::World::getAddressesSimpleVoxelObjectsByFace ( VoxelAddress * addr,
SimpleVoxelEngine::Additional::Vector3d< int > vect,
bool withempty = false )

Получение адресов всех соседей у грани вокселя.

Возвращает ячейки, которые касаются грани с другой стороны, хотя бы частично, на любой глубине: блоки внутри вложенных чанков, более мелкие ячейки соседнего чанка с другим разбиением, а если сосед крупнее - адрес этого крупного блока (короче addr). Вложенные чанки в список не входят - вместо них их ячейки. Это те же ячейки, которые проверяет isFaceTransparent(). Порядок: по z, затем y, затем x на каждом уровне. В отличие от getAddressSimpleVoxelObjectByShift(), которая возвращает одну ячейку (у нижнего угла грани).

Аргументы
addrАдрес вокселя.
vectНаправление грани: единичный вектор вдоль оси, например (1,0,0) или (0,-1,0).
withemptytrue - включать и пустые ячейки (например, чтобы знать, куда можно поставить блок).
Возвращает
Список новых адресов - удаляет вызывающий. Пустой, если вокселя нет или соседний чанк не загружен.

◆ getAddressSimpleVoxelObjectByPoint()

SimpleVoxelEngine::Core::VoxelAddress * SimpleVoxelEngine::Core::World::getAddressSimpleVoxelObjectByPoint ( SimpleVoxelEngine::Additional::Vector3d< float > point,

SimpleVoxelEngine::Defines::LevelSearchSimpleVoxelObject lssvo = SimpleVoxelEngine::Defines::LASTLEVEL,

Получение адреса SimpleVoxelObject, в котором лежит точка.

Например, точка под курсором, чуть сдвинутая от грани вдоль взгляда: внутрь блока - чтобы найти блок, к камере - чтобы найти ячейку для установки. В отличие от getAddressSimpleVoxelObjectByThreePoints(), находит ячейку именно в этом месте грани, а не у центра треугольника. Если точка лежит ровно на границе ячеек, берётся ячейка с большей координатой - поэтому точку нужно сдвинуть с грани.

Аргументы
pointТочка в тех же координатах, что и точки getAddressSimpleVoxelObjectByThreePoints().
scaleМасштабирование вокселей в пространстве (как в getAddressSimpleVoxelObjectByThreePoints()).
lssvoТип поиска: LASTLEVEL - спуск до вокселя, который не чанк, или до пустой ячейки; NUMBERLEVEL - до уровня level (пустая ячейка или воксель, который не чанк, выше уровня level - ошибка, NULL).
levelУровень глубины погружения при поиске (для NUMBERLEVEL).
Возвращает
Возвращает новый адрес (удаляет вызывающий): адрес вокселя или пустой ячейки, в которой лежит точка; адрес без векторов, если чанк не загружен; NULL при ошибке.

◆ getAddressSimpleVoxelObjectByShift()

SimpleVoxelEngine::Core::VoxelAddress * SimpleVoxelEngine::Core::World::getAddressSimpleVoxelObjectByShift ( VoxelAddress * addr,
SimpleVoxelEngine::Additional::Vector3d< int > vect )

Получение адреса SimpleVoxelObject по сдвигу.

Интеллектуальное определение нового адреса SimpleVoxelObject из сдвига. Учитывает границы чанков, вложенные чанки и разное разбиение чанков (считается точно, в целых числах). Находится ячейка, прилегающая к грани вокселя; результат не глубже addr (спуск останавливается на вокселе, который не чанк, или на пустой ячейке). Если ячейки соседа мельче вокселя, возвращается одна из прилегающих (у нижнего угла грани). Возвращает 0, если исходного вокселя нет или соседний чанк не загружен.

Аргументы
addrАдрес вокселя, от которого идёт сдвиг.
vectВектор сдвига.
Возвращает
Возвращает указатель на VoxelAddres. Необходимо удалить самому, когда будет больше не нужен.

Получение адреса SimpleVoxelObject по трём точкам в пространстве и вектору направления.

Получает адрес SimpleVoxelObject по трём точкам, который он содержит, а также вектору, который в него направлен.

Аргументы
v1Первая точка.
v2Вторая точка.
v3Третья точка.
scaleМасштабирование вокселей в пространстве.
lookvectНаправление взгляда (вектор, торчащий в воксель).
lssvoТип поиска: LASTLEVEL - спуск до вокселя, который не чанк; NUMBERLEVEL - до уровня level (уровень = число векторов в адресе: 1 - чанк, 2 - воксель чанка...; пустая ячейка или воксель, который не чанк, выше уровня level - ошибка); AUTOLEVEL - как LASTLEVEL.
levelУровень глубины погружения при поиске (для NUMBERLEVEL). Работает и для граней вокселей вложенных чанков, и для чанков с любым разбиением. Сдвиг точки за грань учитывает точность float, поэтому поиск работает и далеко от начала координат (пока ячейка больше нескольких шагов float в этом месте).
Возвращает
Возвращает новый адрес (удаляет вызывающий): адрес вокселя, в который направлен взгляд (при LASTLEVEL это может быть и пустая ячейка - например, место для установки блока, если взгляд направлен из блока); адрес без векторов, если чанк не загружен; NULL при ошибке: вырожденный треугольник, взгляд вдоль грани, точка на границе чанков, ошибка уровня NUMBERLEVEL.

Загрузка чанка.

Загружает чанк в память с диска. Если на диске его нет - генерирует с помощью установленного миру генератора. Если генератор не установлен - чанк остаётся пустым (это не ошибка). Если загрузка или генерация не удалась, чанк удаляется из памяти. После загрузки граничные воксели чанка и его соседей помечаются на пересчёт видимости, у вложенных чанков появляются адрес и мир, а счётчик непустых ячеек пересчитывается по массиву (контроллер загрузки может писать в массивы чанка напрямую и ставить счётчик сам - движок его поправит). Чанк за границами мира (setChunksBound()) не загружается и не генерируется (генератор не вызывается).

Аргументы
vectВектор (координаты) загружаемого чанка.

Возвращает
Возвращает true в случае успеха, иначе false (в том числе если чанк уже загружен - нарушение логики в логе - или лежит за границами мира).

◆ setChunksBound()

bool SimpleVoxelEngine::Core::World::setChunksBound ( SimpleVoxelEngine::Defines::WORLD_BOUND_SIDE side,
int chunkcoord )

Установка границы мира с одной стороны.

Мир ограничивается по координатам чанков: чанк за границей не загружается и не генерируется (loadChunk(), generateChunk() возвращают false с нарушением логики в логе - его можно выключить параметром outboundserror = false; генератор не вызывается; loadChunks() и progressiveLoadChunks() такие чанки пропускают молча), его как будто нет - на краю мира видны грани. Каждую из 6 сторон можно ограничить отдельно или оставить без границы (по умолчанию границ нет). Граница включительная: при setChunksBound(WORLD_BOUND_Y_MIN, 0) и setChunksBound(WORLD_BOUND_Y_MAX, 15) существуют чанки с Y от 0 до 15 (то же - setChunksBounds(WORLD_AXIS_Y, 0, 15)). Минимум, равный максимуму, допустим (один слой чанков). Уже загруженные чанки за новой границей не выгружаются - это делает пользователь.

Аргументы
sideСторона границы.
chunkcoordКрайняя допустимая координата чанка по этой стороне.
Возвращает
Возвращает false (граница не меняется, в логе - нарушение логики), если граница получилась бы за противоположной границей той же оси (минимум больше максимума); чтобы передвинуть обе, используйте setChunksBounds(). Иначе true.
