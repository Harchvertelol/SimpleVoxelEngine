Подробное описание

Цвет ARGB.

Данный класс содержит в себе ARGB цвет. Можно использовать для цвета вокселей. Компоненты - unsigned char, арифметика (+, -, *) идёт по модулю 256 (переполнение "по кругу", без насыщения): например, 200 + 100 = 44, 0 - 1 = 255.
