Подробное описание

Главное пространство имён движка. Всё находится в нём.

Отладочные проверки входных данных. Макрос нигде не определяется в коде - он задаётся флагом компилятора -DSVE_DEBUG_CHECKS в Debug-цели проекта (библиотека в lib/Debug). Без флага (Release, сборка без параметров) проверок нет совсем - ради скорости работы с вокселями. С флагом проверяются ошибки программиста: координаты вектора внутри чанка (иначе, например, (16,0,0) в чанке 16 молча попадает в ячейку (0,1,0)), svo == NULL в ChunkVoxelObject::setSimpleVoxelObject(), чанк вне мира (без адреса или мира) при построении меша и пересчёте видимости, отрицательный индекс в VoxelAddress::addVector(). При ошибке пишется EVENT_TYPE_LOGIC_VIOLATION с пометкой "Debug check (SVE_DEBUG_CHECKS)", функция возвращает ошибку. Заголовки от макроса не зависят, поэтому приложение можно собирать с любой из версий библиотек. Данные извне (файлы сохранений, сеть) нужно проверять самому, в своём коде, - и в релизе тоже.
