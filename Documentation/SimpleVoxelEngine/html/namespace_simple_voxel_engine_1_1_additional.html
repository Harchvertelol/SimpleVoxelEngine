Оператор сравнения "равно" для возможности использования класса как индексатора std::map.

Сравнивает с допуском EPS по каждой координате (для int - то же, что точное равенство). Для float это не отношение эквивалентности (a == b и b == c не значит a == c) и не согласовано с точным operator<. std::map пользуется только operator<, поэтому ключи карты сравниваются точно.
